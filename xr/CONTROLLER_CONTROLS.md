# Quest 3 / 3S controller guide

Open the seeker with **B** or the left **Menu** button, then choose **Controllers**
in settings. The same guide and configurable button assignments are shown there.

| Control | Action |
|---|---|
| Either trigger, pointing at UI | Press and release to click. Hold to drag a slider or scroll a list. Either controller can search or focus a textbox. |
| Either trigger, pointing at a white page rail | Hold to grab that page. Pull inward across the spine, then release. The book stays stationary. This works nearby and at ray distance. |
| Release a held page before halfway | Return the page to its original side. |
| Release a held page after halfway | Complete exactly one spread turn. The left rail turns backward; the right rail turns forward. Right-to-left chapters reverse reading order. |
| Trigger on a closed cover's white rail | Hold and pull the cover open. On an open book the rails turn pages; use the book's close control to dismiss it. |
| Either grip on the book body | Hold to carry and rotate the entire book. Release to place it. |
| Both grips on the book | Move the controllers apart/together to resize and rotate the book. Release one to continue carrying with the other. |
| Grip on a window handle | Hold to move the window. Release to place or snap it. |
| Right stick left/right | Flick for one previous/next page turn. Return to center before another turn. |
| Right stick up/down | Scroll long-page reading or a UI list under the pointer. |
| Left stick left/right | Smoothly rotate the view around your headset position. |
| Left stick up/down, aimed away from UI | Target the floor or a stool/chair. Press trigger to teleport to the glowing target. |
| A / X | Click using the preferred pointer hand. |
| B / left Menu | Show or hide the seeker. |
| Y | Open the main library. |
| Right stick click | Recenter the book and workspace around your current view. |
| Left stick click | Switch the preferred pointer hand. Trigger selection still works with either hand. |
| Seeker's book icon: Get book | Recall the current book along a smooth arc and open it for reading. |
| Meta button | Quest system function. |

Choose **Follow source**, **Left to right**, or **Right to left** in Book Options
or Settings → Questium Settings. The direction is saved and applies to new books.
Sideways controller drags curl continuously in both directions with equal travel;
you do not need to lift the controller above the page to make the curl appear.

White rails turn purple when pointed at or grabbed. Tracking loss cancels a held
page without advancing it. A UI press retains its release even if the pointer
moves off the panel; a page grab cannot become a stray UI click.

For source searches, select an installed source, focus its search textbox, type
with the Quest keyboard and press Enter/Search, or click/tap **Search**. A typed
query and selected filters use the source's search API even when Latest was
selected. Searching names in the Sources picker filters source names; it does
not search manga until you choose a source.

**Filters** and **Search by tags** request the selected source's current filter
list. The open sheet refreshes briefly as extension tags load, preserving your
selections. Choose **Apply Filters** to search with them. Reopen Filters if the
source takes longer to load its tags.

At startup, the counter faces forward, and posture calibration retains the
standing reading height or raises a seated view. Subsequent left-stick rotation
and manual recentering stay under your control.
